# 硬件说明（当前样机 v1）

> ESP32-S3-N16R8 + INMP441 数字麦 + MAX98357A 数字功放 + 3W 喇叭
> 本文档记录引脚、接线、电源/抗干扰要求，以及**硬件能力边界**（它直接决定软件方案）

---

## 1. BOM

| 部件 | 型号 | 接口 | 供电 | 关键参数 |
|---|---|---|---|---|
| 主控 | ESP32-S3-N16R8 | — | 3.3V | 双核 240MHz，16MB Flash，8MB Octal PSRAM |
| 麦克风 | INMP441 | I2S（仅输出） | 1.8~3.3V，~1.4mA | 24bit，全向，SNR 61dB，灵敏度 -26dBFS，最高 48kHz |
| 功放 | MAX98357A | I2S（仅输入）+ D 类输出 | 2.5~5.5V | 5V/4Ω 最大 3.2W；5V/8Ω 约 1.6~2W；无需 MCLK |
| 喇叭 | 3020 腔体 | 模拟 | — | 8Ω 2W 或 4Ω 3W 全频 |
| 电源 | 5V/2A 适配器 + 3.3V LDO | — | — | 功放峰值电流可达 ~1A，USB 口供电易掉压复位 |

## 2. 引脚规划

| 功能 | GPIO | 方向 | 说明 |
|---|---|---|---|
| `MIC_BCLK` (INMP441 SCK) | **5** | 输出 | 16kHz × 64 = 1.024MHz |
| `MIC_WS` (INMP441 WS) | **6** | 输出 | 16kHz 帧同步 |
| `MIC_DIN` (INMP441 SD) | **4** | 输入 | 32bit 槽位、左声道有效 |
| `AMP_BCLK` (MAX98357A BCLK) | **41** | 输出 | 48kHz × 32 = 1.536MHz |
| `AMP_WS` (MAX98357A LRC) | **42** | 输出 | 48kHz 帧同步 |
| `AMP_DOUT` (MAX98357A DIN) | **40** | 输出 | 16bit 立体声（单声道数据复制 L/R） |
| `LED` (WS2812) | **48** | 输出 | DevKitC-1 板载 RGB 灯；按实际板子确认 |
| `BUTTON`（用户键/打断键） | **0** | 输入 | 当前用板载 BOOT（GPIO0）；产品化再换独立引脚 |
| `BAT_ADC`（当前不用） | **1**（ADC1_CH0） | 模拟 | 电池方案确定后启用，分压 100k/100k |

**必须避开的引脚**：
- `26~32`：SPI Flash
- `33~37`：Octal PSRAM（N16R8 必占）
- `19/20`：USB D-/D+（USB-JTAG 调试也在这）
- `43/44`：UART0 控制台
- `0/3/45/46`：strapping 脚，上电电平会影响启动模式（GPIO0 做按键可用，但不要在开机时按住）
- `40~42` 与 JTAG 复用，占用后只能用 USB-JTAG（19/20）调试，不影响正常使用

## 3. 接线

```
INMP441                        ESP32-S3                MAX98357A
┌─────────┐                   ┌─────────┐             ┌──────────┐
│ VDD ────┼──── 3.3V          │         │             │ VIN ─────┼── 5V
│ GND ────┼──── GND           │         │             │ GND ─────┼── GND
│ L/R ────┼──── GND（左声道）  │         │             │ BCLK ────┼── GPIO41
│ SCK ────┼────────────────────┼─ GPIO5  │             │ LRC ─────┼── GPIO42
│ WS  ────┼────────────────────┼─ GPIO6  │             │ DIN ─────┼── GPIO40
│ SD  ────┼────────────────────┼─ GPIO4  │             │ SD_MODE ─┼── 电阻到 VDD
└─────────┘                   │         │             │ OUT+ ────┼── 喇叭 +
                              │         │             │ OUT- ────┼── 喇叭 -
                              └─────────┘             └──────────┘
```

### 3.1 INMP441 要点
- **L/R 引脚接 GND** → 数据出现在左声道（对应代码 `slot_mask = I2S_STD_SLOT_LEFT`）；接 VDD 则是右声道。
- 数据格式：24bit 有效数据、装在 32bit 槽位里，代码里 `>> 16` 取高 16 位（与现有实现一致）。
- 麦克风开孔朝外，**不要贴在喇叭腔体上**，两者之间做减震/隔音；麦克风与功放喇叭线保持距离并正交走线。

### 3.2 MAX98357A 要点
- `SD_MODE` 同时负责**关断控制 + 增益选择**（通过到 VDD 的电阻阻值选 3/6/9/12/15dB，具体阻值见 datasheet 表）。**量产固定一个阻值**，音量全部用软件数字音量调。
- 输出是单声道 D 类；I2S 送立体声时，左右声道送同一份单声道数据（或让功放做 `(L+R)/2`）。
- 无需 MCLK，只要 BCLK/LRC/DIN。
- 上电/关断会有轻微 pop：靠软件静音帧 + 淡入淡出规避；需要硬件静音时可用 GPIO 经电阻控制 `SD_MODE`。

## 4. 时钟与采样率

| 通路 | 控制器 | 采样率 | 格式 |
|---|---|---|---|
| 麦克风采集 | `I2S_NUM_0` RX | **16kHz** | 32bit 槽位、单声道、左声道 |
| 功放播放 | `I2S_NUM_1` TX | **48kHz** | 16bit、立体声（单声道复制） |

- 两路**独立时钟**（不同采样率），不共享 BCLK/WS。
- AFE 只吃 16kHz；音乐/TTS 统一重采样到 48kHz 输出，避免运行中切换采样率产生爆音。
- 将来做软件参考 AEC 时，参考信号需要重采样到 16kHz 并与麦克风帧做延迟对齐（见架构文档 2.1）。

---

## 5. 电源与抗干扰（这块最容易被忽略）

1. **功放单独 5V 供电**，不要和 ESP32 共用 USB 口的 5V 细线；峰值电流 ~1A，线径不够会掉压导致 ESP32 重启。
2. 功放 VIN 旁 **470µF 电解 + 100nF 陶瓷**；喇叭输出线远离麦克风信号线与 I2S 时钟线。
3. 麦克风 VDD 旁 **10µF + 100nF**，最好经独立 LDO 或 RC（10Ω+10µF）滤波，D 类功放的开关噪声很容易串进麦克风。
4. 单点接地/星形接地，麦克风地线与功放地线分开走，最后汇到电源入口。
5. 喇叭腔体与麦克风之间做物理隔离；麦克风加硅胶套减震（避免结构传导的低频噪声）。
6. 输入加一颗 1000µF 以上的电容 + TVS，防止热插拔浪涌。

## 6. 硬件能力边界（决定软件方案）

| 能力 | 结论 | 影响 |
|---|---|---|
| 电气回采参考（AEC） | ❌ 不可行 | 麦克风只有 ADC→I2S 输出，功放只有 I2S 输入，没有模拟回采通路 |
| 硬件 AEC | ❌ | 当前只能**半双工**：TTS 播放时丢弃麦克风数据；打断用按键 |
| 软件参考 AEC | 暂不实现 | AFE 支持 `"MR"`/`"MMR"` 显式参考通道，参考=播放器写往 TX 的同一份 PCM；当前不做，见 HARDWARE 第 7 节与架构文档附录 A |
| 双麦阵列/波束成形 | ❌ 当前单麦 | 远场拾音约 2~3m；升级见第 7 节 |
| 数字音量 | ❌ | MAX98357A 增益由 SD_MODE 电阻固定；音量靠软件 16bit 缩放 + 限幅器 |
| 屏幕 | ❌ | 当前无屏，用 WS2812 状态灯 + 提示音 |

## 7. 后续升级路径（非本期范围）

1. **加第 2 颗 INMP441**（约几元）：两颗共用 BCLK/WS，L/R 引脚一高一低 → 双麦输入。配合软件参考通道即可用 AFE `"MMR"`，同时拿到 AEC + 双麦增强（波束成形/降噪）。
2. **换专业 codec**：ES7210（2 路 ADC）+ ES8311（DAC），或 ES8388 单芯片（含 ADC 回采路径）→ 标准 AEC 方案，音质和稳定性最好，但要改板。
3. **加电池 + 电量 ADC**：低电提示与便携使用。
4. **加 SD 卡槽**：本地音乐/日志，减少对网络依赖。

## 8. 上电自检清单（软件 P0 阶段要跑的）

| 检查项 | 方法 | 期望 |
|---|---|---|
| 功放通路 | 播放 1kHz 正弦 3 秒 | 清晰无破音、无 pop、喇叭无持续"沙沙"底噪 |
| 麦克风通路 | 串口打印 16k 采集波形/RMS | 安静时几十~几百 LSB，说话时峰值数千以上 |
| I2S 时序 | 逻辑分析仪看 BCLK/WS/DIN | 16k 时 BCLK≈1.024MHz；48k 时≈1.536MHz，WS 占空比 50% |
| 电源 | 播放最大音量时测 5V 纹波/压降 | 压降 < 0.2V，不触发 ESP32 复位 |
| 麦克风底噪 | 静音、拿开喇叭 | 无周期性"哒哒"声（D 类功放串扰的典型症状） |

## 9. 已知硬件风险

| 风险 | 症状 | 对策 |
|---|---|---|
| 功放峰值电流导致掉压 | 大音量时 ESP32 重启 / 花屏 | 独立 5V、加 470µF、缩短线径 |
| D 类功放噪声串入麦克风 | 静音时能听到周期性干扰、唤醒误触发 | 麦克风独立 LDO、滤波、布线与喇叭线隔离 |
| 麦克风结构传导 | 低频"咚咚"声、VAD 误判 | 减震棉/硅胶套、PCB 开孔设计 |
| MAX98357A 增益固定 | 音量范围窄/爆音 | 软件数字音量 + limiter，必要时改 SD 电阻 |
| 单麦远场弱 | 3m 外唤醒率低 | 后续加第二颗麦；或降低唤醒阈值配合误唤醒测试 |
